## 🚀 Como testar o projeto

1. Clone o repositório ou baixe o projeto:
   ```bash
   git clone <URL_DO_REPOSITORIO>
   cd word-combat/server
   
2. Instale as dependências:
   ```bash
   npm install

4. Inicie o servidor:
   ```bash
   node index.js

5. Abra o jogo no navegador:
   ```bash
   http://localhost:3000
